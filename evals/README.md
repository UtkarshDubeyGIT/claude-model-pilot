# Local evaluation output

The live and offline runners write timestamped reports here. Raw reports stay
ignored by Git because they can contain prompts, answers, session identifiers,
and local paths. Keep these files private and review them before sharing.

Public, sanitized aggregate evidence is in [`benchmarks/results`](../benchmarks/results/).
The interpretation and limitations are in [`docs/benchmark-results.md`](../docs/benchmark-results.md).
